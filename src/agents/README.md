# Agents Module (`src/agents`)

Módulo responsável pela anatomia e personas dos agentes de IA.

- `definitions/`: Configuração dos agentes (ex: Planejador, Dev Backend, Revisor de Código).
- `prompts/`: System prompts e instruções contextuais de cada agente.
- `tools/`: Ferramentas executáveis (function calling) disponibilizadas para os agentes (ex: ler arquivos, editar código, rodar testes).
