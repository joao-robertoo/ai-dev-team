# Orchestration Module (`src/orchestration`)

Motor de orquestração responsável por gerenciar a interação, comunicação e fluxo de trabalho entre múltiplos agentes.

- `state/`: Gerencia a memória da conversa, histórico de tarefas e estado global da colaboração.
- `workflows/`: Define pipelines de colaboração (ex: Planejamento -> Desenvolvimento -> Revisão -> Aprovação).
